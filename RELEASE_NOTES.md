# Notas de la Versión 1.0.0 (Release)

Esta versión consolida el primer entregable del proyecto bajo el modelo de ramificación Git Flow y automatización de integración y entrega continua (CI/CD).

## Cambios incluidos
- Inicialización del proyecto web con Vite y React.
- Configuración del pipeline de GitHub Actions (`.github/workflows/deploy.yml`) para despliegue automatizado en la rama `build`.
- Interfaz gráfica informativa sobre ramas Git Flow y flujo de trabajo.
- Preparación para paso a producción (`main`).
